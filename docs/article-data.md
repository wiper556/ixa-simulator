# 記事用データ置き場

記事の文章はうぐさんが書く。ここには**測定結果と前提条件だけ**を置く。

## 使い方

- 新しいテーマは下に節を足していく。**測定条件・生の数値・注意点**の3つを必ず書く。
- 数値はシミュレーターやページ本体のロジックをそのまま呼び出して取る。手計算や推測は載せない。
- 「この数字はどういう前提のときの値か」を必ず添える。前提が抜けると記事にした時に誤読される。

## 1. 六角定頼(No.1321 / 天弦ノ威軍)を模倣させた場合の火力

測定日 2026-08-09 ／ 攻撃/防御シミュレーターで実測

### 測定条件

| 項目 | 値 |
|---|---|
| 部隊長 | 六角定頼(天弦ノ威軍) |
| 小隊1〜3 | 織田信秀【覇】／今川義元（3）【覇】／松平清康（2） |
| 兵士 | 全員 騎馬鉄砲 |
| 突破 | 天限突破 |
| ステ振り | 攻撃振り |
| 部隊攻撃力 | 1,737,512(全構成で共通) |

武将と兵士は固定し、**小隊に載せる模倣スキルだけを変えている。**
こうすると模倣スキル自体の寄与が切り出せる。

### 結果

| 構成 | 攻撃力上昇 | 最終攻撃力 | 模倣なし比 |
|---|---:|---:|---:|
| 模倣なし(各自の固有スキル) | 4,350% | 77,319,284 | 1.00倍 |
| 転歌(等倍・確率80%) | 12,000% | 210,238,952 | 2.72倍 |
| 入来神舞(1.1倍・確率55%) | 12,900% | 225,876,560 | 2.92倍 |
| 摩利支天ノ法(1.25倍・確率70%) | 14,250% | 249,332,972 | 3.22倍 |
| TR5 + 摩利支天ノ法 | 19,950% | 348,371,156 | 4.51倍 |

### 内訳

- 模倣なしの4,350% = 六角定頼3,000% + 織田信秀1,000% + 松平清康350%
  (今川義元の怪童冥滅は兵士攻撃力への効果なのでこの欄には乗らない)
- 模倣を3枠に載せると 3,000×3 + 3,000 = 12,000%。
  元が1,000%や350%だった枠が丸ごと3,000%に置き換わるので伸び幅が大きい

### 模倣スキル1枠あたりの上昇

| 模倣スキル | 倍率 | 発動率 | 1枠あたり |
|---|---|---:|---:|
| 転歌 | 1.0倍 | 80% | 3,000% |
| 入来神舞 | 1.1倍 | 55% | 3,300% |
| 摩利支天ノ法 | 1.25倍 | 70% | 3,750% |

### 注意点(記事にする際に外せない前提)

1. **上の最終攻撃力は全スキルが発動した場合の値。** シミュレーターは上昇率を合計して
   表示する仕様で、発動率は別に「実発動率」欄で見る必要がある。
   発動率が55%の入来神舞は、表の数字が出るのは約半分の戦闘だけ。
2. **自軍城主数が10未満だと3倍が乗らない。** その場合は表の数字を3で割った値になる。
   サイトのシミュレーターは条件を満たしている前提で登録しており、
   実発動率欄に「城主10以上前提」と注記を出している。
3. **対象兵科は弓・馬・焙・騎。**「騎」は騎馬鉄砲という特定兵種を指すので、
   槍や鉄砲足軽を編成すると発動しない。「焙」は焙烙火矢で砲兵科扱い。
4. 天弦ノ威軍は不屈1を持つ。攻撃戦闘に敗北しても指揮兵が一定数回復する。

### 素の数値(3倍を掛ける前)

LV10 1,000% / TR1 1,060% / TR2 1,120% / TR3 1,200% / TR4 1,300% / TR5 1,400%

## 2. 32章開幕くじ 天12種コンプリートまでの連数

測定日 2026-08-08 ／ くじシミュレーターの抽選ロジックで2万回試行

### 測定条件

くじシミュレーター(gacha-simulator.html)の `drawOne` / `pickCharacter` /
`TIER_CHAR_LISTS` をそのまま呼び出し、天12種(No.1310〜1321)が
1枚以上ずつそろうまで10連を回し続ける試行を20,000回繰り返した。
通常版・パラレル版のどちらでも「そろった」として数えている。

### 結果

| 指標 | 連数 |
|---|---:|
| 最速 | 280連 |
| 上位10% | 770連 |
| 上位25% | 970連 |
| **中央値** | **1,260連** |
| 平均 | 1,355連 |
| 下位25% | 1,630連 |
| 下位10% | 2,050連 |
| 最遅 | 5,650連 |

平均が中央値より大きいのは、極端に長引く試行が分布を引き伸ばしているため。
体感に近いのは中央値のほう。

### 排出確率(1〜9枚目)と実測

| レア度 | 公称 | 実測(50万回) |
|---|---:|---:|
| 傑 | 0.018% | 0.019% |
| 天 | 2.500% | 2.504% |
| 極 | 20.000% | 19.972% |
| 特 | 36.500% | 36.565% |
| 上 | 40.982% | 40.940% |

### 10枚目の確率(1〜9枚目の結果で切り替わる)

| | 傑 | 天 | 極 | 特 | 上 |
|---|---:|---:|---:|---:|---:|
| ブースト(極以上が出ていた) | 0.036% | 10.000% | 40.000% | 9.964% | 40.000% |
| 救済(極以上が1枚も無い) | 0.036% | 10.000% | 89.964% | 0% | 0% |

**救済が発動するのは実測10.12%**、残り89.88%はブースト側。
いずれにせよ10枚目の天は10%で、1〜9枚目の2.5%より4倍出やすい。
10連の天期待値は 2.5%×9 + 10%×1 = 0.325枚 で、単発10回より多い。

### パラレル天

32章では「通常版を引くと以後パラレル確定」のボーナスが廃止され、
抽選テーブル上の確率でしか出ない。**12種合計で0.072%**(1連あたり1,389回に1回)。
天そのものが2.5%なので、**出た天のうちパラレル版は約2.9%**。
