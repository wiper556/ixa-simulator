出典: `https://sengokuixa.jp/skill_kouza/`(運営が公開している一次情報源)。
取得は `curl -s -A "Mozilla/5.0" https://sengokuixa.jp/skill_kouza/`。
WebFetchの許可ドメインに未登録のため必ずBash経由のcurlを使うこと。

2026-07-30/31の調査で「件数が多く未照合」として宿題に残っていた panel-2 / panel-3 を
全件抽出したもの。skillDetail に「模倣不可」「重複不可」を書く/書かない判断はこれで裏取りする。

## 使い方

```bash
# あるスキルが模倣不可かどうか
grep -n '^- 天聖宝冠$' docs/sengokuixa-nomimic-nodup.md
```

**注意**: このリストは「模倣スキルの対象にならない初期スキル(戦闘スキル)」の一覧。
「飛翔獲得部分のみ模倣不可」のような**部分的な模倣不可はこのリストに載らない**ので、
リストに無いことを理由に skillDetail の部分模倣不可の注記を消してはいけない。
