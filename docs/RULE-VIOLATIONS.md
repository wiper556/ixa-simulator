## 根本原因タグ

違反の見た目ではなく、**なぜ通ってしまったか**で分類する。
IDごとに数えると、同じ原因の違反が別IDに散って「2回目」の扱いを免れる
(実際 I-01 と S-01 はどちらも「自己承認」なのに、IDが違うため発火しなかった)。

| タグ | 意味 | 対策の方向 |
|---|---|---|
| 自己承認 | 自分の作業を自分の基準で合格にした。検査を自作して自分で通した場合を含む | 機械のチェックに置き換える。チェックの正しさは`audit_selftest.py`で示す |
| 手順の自己改変 | 決まっている手順を、途中で自己判断で変えた/省いた | 手順を変える前に止めて報告する(RULE-OPERATION.md「ルールが無理だと分かったとき」) |
| 未検証の断定 | 調べていないことを、調べた結果のように書いた | 調べた記録(`reslog`)を証拠として残し、監査が件数を見る |
| 片側だけ更新 | 対になっているデータの片方だけを直した | 監査に対の整合チェックを足す |

新しいタグを足すときは、この表にも1行足す。**その場限りのタグを作らない**
(タグが毎回変われば、根本原因での2回目判定も無効になる)。
