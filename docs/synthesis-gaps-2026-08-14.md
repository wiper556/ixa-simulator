# 合成表の空欄 — 何が要るかの整理(2026-08-14)

合成表で、スキル名だけが出ていて 対象/確率/効果 が空になっている欄の一覧。

## 分かったこと: ixanary から機械で埋めるのは無理

ixanary のスキルページには LV10 の効果が載っているので、そこから
うちの `target` / `rate` / `effectShort` を作れないかを試した。
既に埋まっている行(人が書いたもの)を答え合わせに使った結果:

| 欄 | 再現できた |
|---|---|
| `rate`(確率) | 42 / 42 |
| `target`(対象) | 34 / 42 |
| `effectShort`(効果) | 3 / 42 |

`effectShort` はうちで短く書き直した文で、ixanary の原文からは作れない。
しかも**既存の書き方自体が揃っていない**。注記の無い単純なスキルだけに
絞っても再現できなかった:

```
八咫烏    いま 砲器 / 35% / 防御30%上昇
          ixanaryから作ると 砲・器(区切りが違う)
十字飛車  いま 攻撃77%上昇(防御77%上昇・破壊50%上昇)
          ixanaryから作ると 攻撃77%上昇+防御77%上昇+破壊50%上昇
```

つまり埋めるには、1件ずつ書き方を決めることになる。
保留中の短縮文7件と同じ種類の判断なので、そちらと一緒に決めたい。

## 確率だけ欠けていた105箇所は埋めた(2026-08-14)

上の147箇所とは別に、**対象と効果は入っているのに確率だけ空**という行が
105箇所あった(以前の把握「254行」は、この2つを合わせた数だった)。

確率は判断が要らない唯一の欄なので、3つの出どころで裏を取って埋めた。

1. そのスキル自身のページの `baseRate`
2. 他の武将の合成表で既に埋まっている値
3. ixanary のスキルページ LV10 の「確率：+N%」

**2つ以上が一致したものだけ**書いた(100箇所 / 55種)。書式は V-07 に従い
「+」は付けない。監査の「移植前の数値矛盾」が `baseRate` と突き合わせるので、
食い違う値を書けば止まる。
