# ルール一覧(唯一の索引)

このファイルは**ルールの全体像を1枚で見るための索引**。本文はここには書かず、原文の場所を指す。

なぜ作ったか: 2026-08-12、ルールが `docs/character-registration-manual.md`(612行)・メモリ38件・
コード内コメントに散らばっていて、**エージェントもユーザーも全体を把握できない状態**だった。
その結果「Sランクは全部ページを作るルールはどこへ行った」「複数サイトで調べるルールはどこへ行った」と
既存ルールの取りこぼしを2件続けて指摘される事故が起きた。どちらもルール自体は書かれていた。

## この索引の使い方

| 列 | 意味 |
|---|---|
| 機械 | ○=データだけで判定できる / △=一部だけ / ×=人の目が要る |
| 監査 | ●=`tools/audit_characters.py`が見ている / ✗=見ていない |

**運用の大原則: 監査が✗のルールは「守られない」ものとして扱う。**
2026-08-12までの実績で、監査●の範囲では違反が出ていない。手作業で見つかった不備は
すべて✗の範囲から出た(リンク切れ203件・コスト未設定205件・段飛び53件・S以上のページ未作成89件)。

**新しいルールを作ったら、同時に監査へチェックを足す。足せないなら、そのルールは
「人が毎回確認する」という運用コストを誰かが払うことを意味する。** 払えないなら作らない。
