### 1体あたりの実測手順(No.2398で確立)

1. `curl https://ixanary.com/cards/{No}/` → 成長値・かな・コスト・指揮兵数・イラストレーター・
   **スキルの正式名称**(カードの装飾フォントは誤読しやすい)
2. `curl https://ixanary.com/skills/{スキル名}/` → LV1/LV10/TR別の効果、
   **合成テーブルの1次(=skill)・2次(=afterSkill)**
3. ランク適性(rankGrades)はカード画像の兵科アイコンを5倍に拡大して読む
   (ixanaryには載っていない)
4. 合成候補スキルの対象・確率・効果はサイト内の既存登録から転記して表記を揃える
5. `python tools/crop_card.py {No}` で TYPE1/TYPE2 を切り抜き、目視確認
6. `characters-kyoku.html` に追記(reviewedOk/approvedは付けない=青丸)
7. ブラウザで表示確認

**カード画像だけでは確定できない項目**: 成長値・合成テーブル・TR・rankGrades。
1〜2でほぼ埋まるが、章(ch)だけはどのソースにも無いため`"未確認"`とする
(既存の極武将29体中14体も`"未確認"`)。

### 見つかった誤読

No.2398のスキル名はカード画像では「神変**譎**略」に見えるが、
ixanaryのskillsリンクでは「神変**機**略」。**カード画像の目視だけでスキル名を確定しないこと。**

## 登録に足りていないもの(外部ソースが必要)

カード画像(Lv.0表示)からは以下が読み取れないため、30体とも登録を保留している。

1. **成長値(atkGrowth / defGrowth / tacticsGrowth)** — Lv.0のカードには基礎値しか出ない
2. **synthesisTable(合成テーブル A/B/C/S1/S2)** — カードに一切記載が無い
3. **鍛錬レベル別性能(trTable の TR1〜TR6)** — カードはLV10のみ
4. **章(ch)** — カードに記載が無い
5. **rankGrades** — カード左下のアイコンから読めるが、30体分を正確に転記できていない

いずれもマニュアルA-3/A-4の手順で外部ソース(ixanary.com / 45do.info 生HTML /
ixagno.blog.fc2.com / ameameixa.com)から確定させる必要がある。
**推測で埋めると[[feedback_no_external_source_citation]]・
[[project_registration_streak_condition]]に反するため、1体ずつ手順どおりに進めること。**
